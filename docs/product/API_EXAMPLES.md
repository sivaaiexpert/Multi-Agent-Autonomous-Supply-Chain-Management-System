# API examples (captured from real calls)

Generated by `python -m scripts.capture_api_examples` against a SYNTHETIC demo tenant (`acme-demo`) with the in-process app. Each response below is the actual output of the request above it (long bodies truncated with `...`; API keys masked as `scm_...`). Identifiers and timestamps differ per run.

Base path `/api/v1`. Authenticate with `X-API-Key: <key>` or `Authorization: Bearer <key>`. Errors are always `{"error": {"code", "message", "request_id"}}`.
